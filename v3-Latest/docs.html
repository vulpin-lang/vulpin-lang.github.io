Docs

The full command reference is short — that's the point.

Vulpin programs are one command per line, each starting with a single letter or symbol. Spaces are optional — G"hi" and G "hi" are the same — and you can pack several commands on one line with ;. Every command below is what the interpreter actually runs — this is the same reference you can try live in the playground.

Output & input

CmdMeaningExample
GPrint a value, with a newlineG"Hello World!"
g / PPrint without a newlineg "loading..."
G + '''Print a multi-line text blockG '''
line one
line two
'''
KRead typed input into a variableKnum"Guess (1-10): ""I"

The letter at the end of K is the input type:

I int, F float, N number, L letter, W word, E lowercase, U uppercase, A words with spaces, P password-ish (word with digits)

Variables

CmdMeaningExample
=Assign a variable — no command letter neededx = 10
EAssign with the classic formE x = 3
AAdd to (and create) a variableA"x"+5
SReplace text in a string variableS"name""Vul""VUL"
DDelete a variable (a number delays instead)D"x"

Note on division: 7/2 is 3 — integer division truncates toward zero. Write 7.0/2 when you want 3.5.

Lists, Dicts & Sets

CmdMeaningExample
[]List — index with [], negative index counts from the endl = [1, 2, 3]
l[0] = 99
{}Dict — key : value pairsd = {"a": 1}
d["c"] = 3
{}Set — unique values; + union, - differences = {1, 2, 3}
s + {4}
inMembership test? 2 in s

Built-ins for containers: len, push, pop, keys, values. Empty {} is always a Dict.

Imports

CmdMeaningExample
UImport a module: math, random, osU"math"
G math.sqrt(16)

Handy modules: math.sqrt, math.pow, random.randint(1, 10), os.system("echo hi"). Latest release: V1.0.3 — check your install with vulpin version.

Strings & built-ins

Shortcuts on a string (also on $var references):

  • $msg.U upper case, msg.L lower case, msg.S strip, msg.T title case, msg.C capitalize

Built-in functions:

abs, floor, ceil, round, sqrt, pow, len, push, pop, keys, values, upper, lower, title, char, ord, rand, min, max
