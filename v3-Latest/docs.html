The full command reference is short — that's the point.

Vulpin programs are one command per line, each starting with a single letter or symbol. Every command below is what the interpreter actually runs — this table is generated from the same rules that power the playground, so it won't drift out of date.

Strings & built-ins

  • s.U upper case, s.L lower case, s.T title case, s.C character code
